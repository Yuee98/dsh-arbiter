# 本地工作流标注网页

使用 `pnpm evals annotate <dataset>` 启动单人本机标注页。服务只监听 `127.0.0.1`，终端打印带本次访问令牌的 URL；用浏览器打开，按 Ctrl+C 关闭。默认只选 dev，不调用模型，不操作 Git。

```sh
pnpm evals annotate /absolute/path/to/dataset --split dev --group f01 --reviewer your-name
pnpm evals annotate /absolute/path/to/dataset --split calibration --group f01 --mode assisted
```

数据集需要已有 `workflows-v1` 分组；历史 `legacy-v1` 继续使用原有工具。省略 `--group` 选择该 split 的工作流组。`--context context.json` 使用共享生产协议及预算配置；`--port 0` 默认分配空闲端口，也可指定端口。未知、重复或不完整参数报错。

左侧显示中性工作流编号、点位、进度和筛选，分别标明当前适用人工参考与本地工作区状态。既有人工标签、外部删除或修改会反映到正式进度；盲标只接收状态，不接收其他人的答案。中间只展示当前点实际经过预算、裁剪和脱敏后的请求，保留来源与缺失说明，协议文本可折叠。变化只比较源中声明且经校验的前点，保留重复出现次数与顺序，不用数组相邻点推断时间，也不显示前点已删除的原文。材料准备失败的点保留在列表中并禁止确认，其他点仍可继续。

右侧的完整 R/A 配对每行写 `risk,authorization`，取公开 1–10 整数。多个配对不扩成笛卡尔积。独立行为由人填写，可与当前矩阵不同。评分确认要求配对、独立行为、理由、作者和当前材料中的逐字证据。也可明确勾选“无分数行为参考”确认独立行为，保存 null 分数，不能把普通空白分数默认为这一选择；填写的证据仍须在当前材料中可定位。材料不足、争议和要求复核也可保存为未确认状态，仍需作者和理由。量表随时可查。

决定日期由服务生成，页面显示本批已保存标签或待恢复确认意图中的 UTC 日期；未提交的草稿没有决定日期。刷新、重启或浏览器日期改变不会改写历史日期。

输入停止约半秒后保存本地草稿；导航及确认前先保存。自动草稿不创建人工标签。“确认并写入当前点”调用共享人工导入服务，逐点更新 `labels.json`，保留模型意见及机器参考各自来源。“确认并下一条”只在当前点成功保存后前进，失败或部分发布时留在当前点；不会确认未审点。快捷键：Ctrl/Cmd+S 保存草稿、Ctrl/Cmd+Enter 确认、Alt+左右切点。

保存失败保留输入并提示重试。相关材料、人工决定或草稿被外部修改时提示冲突；普通格式化、作者备注及当前视图外的变化不会使已审点自动作废。“重新打开材料并复核”严格检查草稿 revision；有较新草稿时同时保留当前表单和较新版本，必须明确选择后再复核。未结算确认意图不能被 rebase 清除，应先采用并恢复相同确认。

盲标从启动到保存/确认都不读取模型意见或候选成绩。辅助模式也不预载意见，主动展开当前点才加载意见、共享动态 K/N 共识和未采用原因，支持收起与再次展开刷新；选入某份意见或合法共识都只填草稿。意见缓存绑定有效视图，材料失效或重新绑定后不能继续选用旧意见。页面标明辅助模式与意见曝光，两个模式分别保存工作区，不把辅助修订称为独立初判。分歧筛选按共享共识语义覆盖主动查看过的点，不预取未来点意见。用户抽检标记不是正式随机抽样计划或参考资格认证。

草稿和私有单点基准在工程 `.local/evals/workflow-annotation/web-<scope>/`，按数据集、split、group、context、mode 恢复。同参数重启后打开新打印的 URL 即可续标。不要手改使用中的私有批次；并发写入或遗留锁会报冲突，不自动删除活跃锁。源成员变化需要先检查批次范围，不能静默丢点。

标签、批次检查点和草稿状态分别落盘。提示标签已发布但恢复状态未保存，或结果尚不确定时，保留原表单并重试相同确认；持久确认意图保留原日期和目标，重启也可恢复。网络失败不等同于标签未写入。

若其他人工写入造成原确认无法重试，可以明确选择“核对当前标签并结算这次确认”。服务在共享组锁下比较同一共享构造器生成的目标与当前标签：匹配则补完私有检查点；不匹配则只结束本地意图、保留原表单为草稿，再重新打开材料复核。该操作不删除或改写正式标签；无法读出确定结果时保留意图。

## 可复现工程验证

```sh
# 临时 synthetic 数据、隔离 DSH_HOME、实际 CLI、esbuild 与 Chromium
pnpm exec playwright test tests/e2e/annotation-web.spec.ts
pnpm test:ui
pnpm test:unit
pnpm test:integration
pnpm check:evals
pnpm verify
```

浏览器脚本验证编辑、自动保存、刷新、SIGTERM 关闭、CLI 重启、续标、单点确认及文件回读，检查没有模型意见请求或作者/未来标记。结果和截图在 ignored 的 `.local/cw-128/browser-result.json`、`browser.png`。脚本清理自己创建的临时数据、DSH profile 和私有工作区。受限沙箱需要允许回环监听与浏览器子进程。

这些合成工程测试不代表真实模型质量或真人标注已完成；正式参考资格和随机抽检计划由相应任务决定。本工具不修改宿主插件加载、UI 或生命周期；宿主 E2E 由相关宿主任务承担。
