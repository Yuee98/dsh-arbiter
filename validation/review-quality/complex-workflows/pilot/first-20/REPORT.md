# 首批 20 点标注试标

本阶段覆盖 dev 的四个合成工作流和 20 个审查点，归属 [#136](https://github.com/Yuee98/dsh-arbiter/issues/136)。四组源题、选集和标注配置取自主线提交 `6ae7cd2`。统计使用 [#203](https://github.com/Yuee98/dsh-arbiter/pull/203) 中的评分共识代码，代码变更头为 `91129b5`。源材料形成了 20 个可评视图。剩余 97 点属于 #136 的后续阶段。

输入入口为 [首批选集](../../../../../evals/plans/cw-136-pilot-points.json) 与 [标注上下文](../../../../../evals/plans/cw-136-annotation-context.json)。使用 decision 协议，常态预算 6,000 tokens，硬上限 10,000 tokens，禁用项目规则。四组源记录与本地试标使用副本一致，答卷及人工标签均核对到相同有效视图。

## 发题与回收

- [外层 agent 提示词](agent-v2.txt)记录实际初轮交接。其中的作答会话只收到本题的单题任务说明入口。
- [单题任务说明](task-v2.txt)保留实际评分要求。共核对四个模型的 80 条初始任务及 4 条重试任务，评分说明只存在路径差异。每题材料文件包含题号和 `productionRequest`。
- [答案结构](answer-format-v2.json)保存同批题本中的字段模板。实际单题要求用一组 1–10 的 R/A 配对或 `null` 替换模板里的空 `pairs`。该轮还要求独立填写 `behaviourReference`，并给出理由、逐字证据和冲突说明。
- [Kimi 第一轮重试](kimi-retry-1.txt)补充了分段读完整材料、定位待审动作及证据截取要求，覆盖 `cw135-001-p03`、`cw135-001-p04` 和 `cw135-007-p03`。[第二轮重试](kimi-retry-2.txt)要求在解开外层 JSON 后核对 `productionRequest.state` 中的精确引用，覆盖 `cw135-001-p03`。
- 新版题本与旧答卷区分留痕。首批意见按实际 v2 规则取得。发布时使用新规则重算 R/A 共识，历史独立行为保留在答卷中。页面所示默认行为由矩阵派生。

本批共有 GPT-6.2 Astra、Gemini 4 Carbon、Claude Opus 5.5、Kimi K3.1 Pro 四个参与模型。每点各有四份最终有效意见。GLM 对照和已作废 v1 仅留本地，不参与本轮统计。耗时、token 用量和费用缺少足够记录，均标为未知。四份未通过验证的尝试都来自 Kimi 的逐字引用，涉及初答三份与重试一份。保留尝试和原有效选票。没有视图构建失败。对裁剪导致的判断变化未做独立对照。

## 公开归档边界

意见与标签写入各自原业务组。意见保留 84 份经审阅的原文、80 条登记及模型身份、评分和证据。标签包含 10 条原有人工作答与按同一视图重算的 11 条模型暂定评分。报告按人工作答优先读取生效记录。人工确认人使用统一代号 `pilot-reviewer`，日期、状态、配对与其余裁决内容保留。原始转交和回收目录继续存于本机，公开记录移除回传元数据里的私有源批次与题号映射。提示词副本将设备路径和随机题号替换为占位符。
